## Tout-en-un
- [PayloadsAllTheThings](https://github.com/swisskyrepo/PayloadsAllTheThings) - Collection de payloads et bypass.
- [HackTricks](https://book.hacktricks.xyz/) - Référénce.
- [CyberChef](https://gchq.github.io/CyberChef/) - Couteau suisse
- [GTFOBins](https://gtfobins.github.io/) - Exploiter les binaires Linux (SUID, Sudo).
- [LOLBAS](https://lolbas-project.github.io/) - Equivalent de GTFOBins pour les binaires Windows.

## Cours
- [hacksplaining](https://www.hacksplaining.com/lessons) - Cours interactifs sur les vulnérabilités web.

## Reverse Shells
- [RevShells](https://www.revshells.com/) - Générateur automatique de payloads.
- [PentestMonkey](https://pentestmonkey.net/cheat-sheet/shells/reverse-shell-cheat-sheet) - Fiche de référence.

## Deobfuscation
- [Beautifier](https://beautifier.io/) - Rendre le code JS/HTML/CSS lisible.
- [Deobfuscate](https://deobfuscate.io/) - Nettoyer les scripts offusqués.
- [JSNice](http://jsnice.org/) - Analyse et "re-nommage" de variables JS.
- [UnPHP](https://www.unphp.net/) - Décoder les malwares ou scripts PHP complexes.

## Outils / Scripts (PrivEsc)
- [PEASS-ng (linPEAS/winPEAS)](https://github.com/peass-ng/PEASS-ng) - Le standard actuel pour l'énumération automatique.
- [LinEnum](https://github.com/rebootuser/LinEnum) - Script d'énumération Linux léger.
- [pspy](https://github.com/DominicBreuker/pspy) - Espionner les processus Linux en temps réel sans être root.
- [PowerUp](https://github.com/PowerShellEmpire/PowerTools/tree/master/PowerUp) - Vérifier les mauvaises configurations Windows.

## Crypto & Hashes
- [CrackStation](https://crackstation.net/) - Lookup de hashes massif via base de données (instantané).
- [Hashes.com](https://hashes.com/en/decrypt/hash) - Identification et décryptage de hashes.
- [dCode](https://www.dcode.fr/) - Outil pour la cryptographie classique (César, Vigenère, etc.).

## Active Directory & Windows
- [BloodHound](https://github.com/BloodHoundAD/BloodHound) - Visualiser les chemins d'attaque dans un domaine AD.
- [Impacket](https://github.com/fortra/impacket) - Suite de scripts Python pour manipuler les protocoles réseau.
- [Ired.team](https://www.ired.team/) - Notes techniques très détaillées sur l'exploitation Windows.

## Wordlists
- [SecLists](https://github.com/danielmiessler/SecLists) - La collection de wordlists la plus complète (users, passwords, fuzzing).
- [Weakpass](https://weakpass.com/) - Pour trouver des dictionnaires de mots de passe massifs.
